# 📈 恐懼貪婪指數 (FGI) 智慧回測專案 PRO

本專案致力於量化研究 **CNN 恐懼與貪婪指數 (Fear & Greed Index, FGI)** 對股票與 ETF 投資策略的實證效果，並將其與經典的 **定期定額 (DCA)** 及 **買入持有 (Buy & Hold)** 進行深度回測對比。

---

## 📌 基礎核心原理（嚴格保留，未做任何變更）

1. **資金進出與薪水投入規則**：
   - 支援起始本金（`initial_capital`）與每月初固定薪水追加投入（`monthly_add`）。
   - 每逢月度更替時，若有薪水投入即注入現金帳戶並計入累積總成本。
2. **定期定額（DCA）邏輯**：
   - 每月固定發薪或只要手中有現金，即以當日收盤價全數扣除交易手續費後買進股票持有。
3. **FGI 恐懼貪婪混合戰法（FGI Timing）**：
   - **狀態 A（持股中）**：
     - 若當日指數超越賣出門檻（`FGI > sell_threshold`）：觸發「**貪婪清倉**」，將所有股票賣出變現，扣除證交稅與券商手續費。
     - 若未觸發賣出，持有期間新發的月薪現金直接以當日收盤價「**持股加碼**」買進。
   - **狀態 B（空手中）**：
     - 當市場情緒降至買入門檻以下（`FGI < buy_threshold`）且手上有現金時：觸發「**恐慌梭哈**」，全額買入。
4. **真實交易磨擦成本**：
   - 券商交易手續費：預設 0.1425%（支援 6 折 0.0855%）。
   - 證券交易稅：台股/美股 ETF 0.1%，台灣一般股票 0.3%。

## 🚀 專案重大優化亮點

1. **智慧數據管線與自動無縫更新 (`create_fgi_dataset.py`)**：
   - 整合 GitHub 歷史歸檔（2011-2023）與 CNN 官方即時 API（近一年數據），自動縫合至**最新日期**（2011-01-03 至 2026 年最新交易日，共 3,674+ 筆）。
   - 具備離線回退保護，即使網路斷線也不會沖銷或遺失已有歷史資料。
   - 同步儲存至多個相容檔名（`FGI_all.csv`、`FGI_Final_Complete.csv`、`FGI_Final.csv`）。
2. **極速純數值模擬與網格最佳化 (`backtest_logic.py`)**：
   - 最佳化階段採用純陣列數值演算，避免高頻建立字典與格式化字串，網格搜索速度**提升 5~10 倍**！
3. **指標維度深度擴充**：
   - 新增 **最大回撤 (MDD %)**、**累積總報酬率 (%)**、**淨獲利金額**、**賣出勝率 (%)**、**交易次數**、**手續費與稅金總摩擦成本**。
4. **全方位標的字典支援**：
   - 擴充涵蓋台灣主流 ETF（0050, 0056, 00878, 00919, 00929, 00713, 006208 等）、台股權值股（台積電、鴻海、聯發科等）與美股指標（SPY, QQQ, VOO, NVDA, TSLA, AAPL 等）。
5. **yfinance 行情快取機制**：
   - 後端具備記憶體快取（TTL 1小時），避免重複查詢同檔股票觸發 Yahoo 限制或拖慢速度。
6. **全新互動式戰情室 (`index.html`)**：
   - 頂部即時顯示今日市場 FGI 情緒指針與顏色警示。
   - 支援時間區間快捷鍵（近3年、近5年、近10年、歷史全部）與標籤一鍵加入熱門股票。
   - 新增「**綜合回測天梯榜**」，橫向對比多檔股票的勝負與超額獲利。
   - 交易日誌支援「全部/買進/賣出」篩選，並提供「**一鍵匯出 CSV 檔**」。
7. **一鍵啟動體驗 (`啟動回測系統.bat`)**：
   - 雙擊批次檔即可自動啟動伺服器並自動開啟預設瀏覽器。

## 📂 專案檔案結構

| 檔案名稱 | 說明 |
| :--- | :--- |
| `啟動回測系統.bat` | **推薦一鍵啟動**：啟動 Flask 伺服器並自動開啟網頁戰情室 |
| `server.py` | 後端 Flask 伺服器，提供 `/api/backtest`、`/api/fgi/latest` 及網頁靜態託管 |
| `index.html` | 專業深色金融回測戰情室前端介面 |
| `backtest_logic.py` | 回測核心模組，封裝 DCA、FGI 混合戰法、網格搜尋與風險指標運算 |
| `create_fgi_dataset.py` | CNN API 與歷史數據更新管線 |
| `app.py` | Streamlit 互動回測應用程式（可透過 `啟動Streamlit版.bat` 執行） |
| `tw_stock_battle.py` | 命令列多標的戰鬥回測對決腳本 |
| `best_strategy.py` | 單筆投入最佳化與買入持有對比腳本 |
| `best_strategy_v2.py` | 定期定額 vs FGI 對決腳本 |
| `FGI_all.csv` | 完整恐懼貪婪指數歷史資料庫（2011~至今） |
| `操作指南(請看我後再操作).txt` | 簡易操作指引純文字檔 |
