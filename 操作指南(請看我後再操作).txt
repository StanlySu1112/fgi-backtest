========================================================
  恐懼貪婪指數回測專案 - 簡易操作指南 (請先閱讀本指南)
========================================================

【方式一：一鍵最速啟動 (推薦)】
直接滑鼠點兩下專案資料夾內的：
👉「啟動回測系統.bat」
系統會自動啟動後端運算引擎，並在瀏覽器自動開啟回測戰情室！

--------------------------------------------------------

【方式二：手動終端機操作】
步驟一：
開啟命令提示字元 (cmd) 或 PowerShell，切換至本專案目錄：
cd "C:\Users\su288\OneDrive\Desktop\01_量化與交易專案\恐懼貪婪指數回測專案"

步驟二 (更新數據，可選)：
python create_fgi_dataset.py
(會自動從 CNN 官方 API 下載最新恐懼貪婪指數，無縫銜接至今天)

步驟三 (啟動伺服器)：
python server.py
(請保持視窗開啟，不要關閉)

步驟四 (開啟回測網頁)：
直接在瀏覽器輸入網址：
http://127.0.0.1:5000
或直接雙擊打開專案中的 index.html

步驟五：
自由選擇投資標的 (如 0050、台積電、SPY、NVDA 等)、時間區間、資金計畫，
點擊「🚀 開始精算回測」，即可即時查看績效圖表、超額獲利與詳細交易流水帳！

--------------------------------------------------------

【方式三：Streamlit 互動版】
直接雙擊「啟動Streamlit版.bat」
或於終端機執行：streamlit run app.py
